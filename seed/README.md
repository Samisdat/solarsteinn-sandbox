# solarsteinn sandbox

This is the review target of the [solarsteinn](https://github.com/Samisdat/solarsteinn) test sandbox.
Nothing here is real code: every file is a "hello world" with a tour of its language's syntax, so that
syntax highlighting, chunking and diff handling have something to chew on.

The open pull requests are generated and refilled nightly. Review them with
`solarsteinn <PR-URL> --log ~/.solarsteinn/sandbox.jsonl`. Anything you merge, close or comment on is
replaced by a fresh copy of the same scenario at the next run.

How it works lives on the `control` branch.
